  attacks: [('a1', 'a2'), ('a2', 'a3'), ('a3', 'a4'), ('a3', 'a5')]
  everybody truthful -> outcome {a1,a3} (book: {a1,a3})
  utilities  x: 1  y: 0  z: 1   (book prints y and z swapped - misprint; code uses each agent's own set)
  x hides a1 (Figure 5.4(b)) -> outcome {a2,a4,a5} -> utility of x = 2 (book: 2)
  best responses of x when the others are truthful: utility 2, reports ['{a4,a5}']
  best responses of y when the others are truthful: utility 0, reports ['{}', '{a2}']
  best responses of z when the others are truthful: utility 1, reports ['{a3}']
  Theorem 5.3 check (best-response form) holds? False
     counterexample: {'agent': 'x', 'truthful_utility': 1, 'deviation': '{a4,a5}', 'deviation_utility': 2} others: {'y': '{a2}', 'z': '{a3}'}
  Theorem 5.3 check (literal inequality form) agrees? True
  Theorem 5.4 condition holds? False
     agent x: odd path a1 ~> a4: a1 -> a2 -> a3 -> a4 (length 3)
     agent x: odd path a1 ~> a5: a1 -> a2 -> a3 -> a5 (length 3)
  => not strategyproof, and the condition correctly fails.

Example 5.11 / Figure 5.5: x also owns a6, extra attack (a6,a3)
  everybody truthful -> outcome {a1,a4,a5,a6} (book: {a1,a4,a5,a6});  utility of x = 4 of 4
  strategyproof? True | Theorem 5.3 literal check: True
  Theorem 5.4 condition holds? False
     agent x: odd path a1 ~> a4: a1 -> a2 -> a3 -> a4
     agent x: odd path a1 ~> a5: a1 -> a2 -> a3 -> a5

D. THEOREM 5.4 - condition holds / condition fails
==============================================================================
Condition HOLDS (non-vacuous): agent 1 = {a,b}, agent 2 = {c}, attacks a->c, c->b.
  The only path from a to b is a->c->b, of EVEN length 2.
  condition: True | strategyproof: True

Condition FAILS and mechanism NOT strategyproof: agent 1 = {alpha,beta}, agent 2 = {d,e},
  attacks alpha->beta, alpha->d, d->e, e->alpha  (alpha,d,e form an odd cycle)
  truthful outcome: {} -> utility of agent 1 = 0
  best response of agent 1: ['{beta}'] -> utility 1 (hiding alpha frees beta)
  condition: False | strategyproof: False
     agent 1: odd path alpha ~> beta: alpha -> beta
     agent 2: odd path d ~> e: d -> e
     agent 2: odd path e ~> d: e -> alpha -> d -> e -> alpha -> d

Same attacks, one argument per agent (no agent holds two arguments, condition vacuous):
  condition: True | strategyproof: True

E. CYCLES in the odd-path test
==============================================================================
attacks: [('x', 'b'), ('x', 'y'), ('y', 'z'), ('z', 'x')]   (x->y->z->x is a 3-cycle)
 odd path x ~> y?  walk: True  ['x', 'y']   simple path: True
 odd path y ~> x?  walk: True  ['y', 'z', 'x', 'y', 'z', 'x']   simple path: False
 odd path z ~> b?  walk: True  ['z', 'x', 'y', 'z', 'x', 'b']   simple path: False
A 'walk' may go around a cycle (repeat nodes); a 'simple path' may not. Both readings are
implemented; the experiments report both. Walk search = BFS over (node, parity) states, so it
always terminates even though cycles make the number of walks infinite.
